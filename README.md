# ARCenal Portail pour YunoHost

Portail d'accueil ARCenal, installé comme application web YunoHost. Il ne
modifie ni le cœur YunoHost ni WebAdmin.

## Installation

Installez le paquet depuis le catalogue ARCenal, puis choisissez le domaine et
le chemin du portail. Le chemin proposé est `/arcenal`.

Les fichiers statiques et la configuration Nginx sont gérés par les ressources
natives YunoHost. La désinstallation ne retire que les fichiers du portail.
